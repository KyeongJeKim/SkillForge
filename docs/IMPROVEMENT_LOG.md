# SkillForge 개선 기록 (Improvement log)

SkillForge의 재귀적 자기개선(RSI) 기록입니다. 규칙은 [PLAN.md 12장](PLAN.md#12-재귀적-자기개선-rsi-recursive-self-improvement)에 있습니다.
새 기록은 아래 양식 바로 다음, 가장 위에 추가합니다. 점수는 같은 모드(sweep / full)끼리만 비교합니다.

## 기록 양식

```markdown
## YYYY-MM-DD: <한 줄 요약>

- 모드: sweep | full (모델: SkillForge / 가상 사용자 / 판정)
- 가장 약했던 항목: <항목> (<점수>)
- 조사한 곳과 차용한 것: <출처 링크> → <무엇을 어떻게>
- 바꾼 것: <1~3가지>
- 점수 전후: | 항목 | 전 | 후 | (개발용, 고정 시험지, 시작 문구)
- 채택: 예 | 아니오 (이유)
- 배운 점: <다음 루틴이 알아야 할 것>
- 비용: $<금액>, <분>
- 커밋: <링크>
```
