DELETE`·`FOR UPDATE` 모두 DB 가 거부, 실패 뒤 다음 조회 정상(처음 판은 실패한 트랜잭션이 남아 다음 조회까지 막혀서 고침). **MySQL 은 서버가 없어 실행 확인 못 함**(문서 기준). 단위 테스트 5개.
