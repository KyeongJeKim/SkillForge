# FS-POS-021 부분 환불

| 항목 | 내용 |
| --- | --- |
| 기능 ID | FS-POS-021 |
| 작성자 | 김철수 |
| 버전 | 1.3 |
| 관련 화면 | SCR-PAY-01 |
| 상태 | 확정 |

## 1. 개요
한 거래의 일부 품목만 선택해 환불합니다.

## 2. 사용자 및 권한
- 캐셔: 실행 가능
- 매니저: 실행 및 승인 가능

## 3. 화면 흐름
1. 결제 화면 진입
2. 기능 버튼 선택
3. 입력 또는 스캔
4. 확인 팝업
5. 완료 후 결제 화면 복귀

## 4. 기능 상세
| No | 요구사항 | 처리 규칙 | 우선순위 |
| --- | --- | --- | --- |
| FS-POS-021-01 | 입력값 확인 | 형식이 맞지 않으면 오류 메시지 표시 | 필수 |
| FS-POS-021-02 | 금액 계산 | 소수점 이하 원 단위 절사 | 필수 |
| FS-POS-021-03 | 이력 저장 | 거래 ID와 함께 로그 저장 | 필수 |

## 5. 예외 처리
| 상황 | 메시지 | 처리 |
| --- | --- | --- |
| 네트워크 끊김 | "네트워크 연결을 확인해 주세요." | 오프라인 대기열에 저장 |
| 권한 없음 | "매니저 승인이 필요합니다." | 매니저 PIN 입력 팝업 |

## 6. 오프라인 동작
- 오프라인에서는 로컬 DB에 저장하고, 연결되면 서버와 동기화합니다.
