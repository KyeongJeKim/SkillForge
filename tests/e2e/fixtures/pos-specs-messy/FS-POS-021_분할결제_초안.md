## 1. 개요
하나의 거래 금액을 여러 결제 수단으로 나누어 결제한다.
지원 조합은 카드+현금, 카드+카드(최대 2장), 카드+포인트이며, 상품권 조합은 2차 범위로 미룬다.

## 2. 화면
- 결제 화면(SCR-PAY-01)에서 [분할 결제] 버튼 → 분할 결제 화면(SCR-PAY-03)
- 상단: 총 결제 금액 / 결제 완료 금액 / 남은 금액
- 중단: 결제 수단 목록 (완료된 수단은 체크 표시와 승인번호)
- 하단: 금액 입력 키패드 + [이 금액으로 결제] 버튼
- 남은 금액이 0원이 되면 [거래 완료] 버튼 활성화

## 3. 기능 상세
| No | 요구사항 | 처리 규칙 | 우선순위 |
| --- | --- | --- | --- |
| FS-POS-021-01 | 분할 횟수 | 최대 3회 (카드는 2회까지) | 필수 |
| FS-POS-021-02 | 금액 입력 | 1원 단위 입력, 남은 금액 초과 입력 불가 | 필수 |
| FS-POS-021-03 | 현금 거스름돈 | 현금은 마지막 결제 수단일 때만 거스름돈 계산 | 필수 |
| FS-POS-021-04 | 중간 취소 | 거래 완료 전 [전체 취소] 시 승인된 카드 건 모두 자동 취소 | 필수 |
| FS-POS-021-05 | 영수증 | 결제 수단별 승인 내역을 한 장의 영수증에 출력 | 필수 |
| FS-POS-021-06 | 포인트 | 포인트는 1회만, 최소 1,000P 이상 | 확인필요 |

## 4. 입력/출력
| 구분 | 항목 | 형식 | 비고 |
| --- | --- | --- | --- |
| 입력 | 분할 금액 | 정수(원) | 키패드 |
| 입력 | 결제 수단 | CARD / CASH / POINT | |
| 출력 | 결제 내역 배열 | [{수단, 금액, 승인번호}] | 거래에 연결 |
| 출력 | 거래 상태 | PARTIAL_PAID / PAID / CANCELED | |

## 6. 권한
- 캐셔: 분할 결제 실행
- 매니저: 승인 완료된 분할 결제 건의 부분 취소 (FS-POS-0030 예정)
