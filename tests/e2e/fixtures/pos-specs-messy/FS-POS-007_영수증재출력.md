# FS-POS-007 영수증 재출력

| 항목 | 내용 |
| --- | --- |
| 기능 ID | FS-POS-007 |
| 기능명 | 영수증 재출력 |
| 작성자 | 박지훈 (POS개발파트) |
| 버전 | v1.2 |
| 관련 화면 | SCR-TRX-02 거래 상세 |
| 상태 | 확정 |

## 1. 개요
완료된 거래의 영수증을 다시 출력한다. 고객이 영수증을 잃어버렸거나 프린터 용지 걸림으로 출력이 실패한 경우에 사용한다.
재출력 영수증에는 상단에 "재발행" 문구가 인쇄되며, 원거래와 구분할 수 있도록 재출력 횟수를 함께 기록한다.

## 2. 화면
- 진입 경로: 메인 > 조회 > 거래 조회 > 거래 선택 > 거래 상세 (SCR-TRX-02)
- 거래 상세 하단 버튼 영역에 [영수증 재출력] 버튼 배치 (보조 버튼 스타일)
- 버튼 탭 시 출력 옵션 팝업 (SCR-TRX-02-P1): 고객용 / 가맹점용 / 둘 다
- 출력 완료 시 토스트 "영수증을 출력했습니다." 2초 노출

## 3. 기능 상세
| No | 요구사항 | 처리 규칙 | 우선순위 |
| --- | --- | --- | --- |
| FS-POS-007-01 | 재출력 대상 | 결제 완료·부분 환불 거래만 가능, 전체 환불 거래는 버튼 비활성 | 필수 |
| FS-POS-007-02 | 재발행 표기 | 영수증 상단 "[재발행]" + 재출력 일시 인쇄 | 필수 |
| FS-POS-007-03 | 횟수 제한 | 거래당 최대 3회, 초과 시 매니저 승인 | 필수 |
| FS-POS-007-04 | 카드 정보 | 카드번호는 앞 6자리·뒤 4자리 외 마스킹 | 필수 |
| FS-POS-007-05 | 이력 기록 | 재출력 일시, 캐셔 ID, 출력 유형을 거래 로그에 저장 | 필수 |
| FS-POS-007-06 | 모바일 영수증 | 회원 거래는 [알림톡 재발송] 버튼 추가 노출 | 선택 |

## 4. 입력/출력
| 구분 | 항목 | 형식 | 비고 |
| --- | --- | --- | --- |
| 입력 | 거래번호 | T-YYYYMMDD-NNNN | 거래 상세에서 자동 전달 |
| 입력 | 출력 유형 | CUSTOMER / MERCHANT / BOTH | 팝업 선택 |
| 출력 | 영수증 인쇄 데이터 | ESC/POS | 프린터 드라이버로 전송 |
| 출력 | 재출력 로그 | JSON | reprint_count 증가 |

## 5. 예외 처리
| 상황 | 메시지 | 처리 |
| --- | --- | --- |
| 프린터 미연결 | "프린터 연결을 확인해 주세요." | 재시도 버튼 노출, 로그 미기록 |
| 용지 없음 | "영수증 용지를 교체해 주세요." | 재시도 버튼 노출 |
| 3회 초과 | "재출력 횟수를 초과했습니다. 매니저 승인이 필요합니다." | 매니저 PIN 팝업 |
| 7일 경과 거래 | "7일이 지난 거래는 본사 시스템에서 출력할 수 있습니다." | 버튼 비활성 |
