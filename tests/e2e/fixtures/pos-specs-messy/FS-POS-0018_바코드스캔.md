# FS-POS-0018 바코드 스캔 상품 추가

| 항목 | 내용 |
| --- | --- |
| 기능 ID | FS-POS-0018 |
| 기능명 | 바코드 스캔 상품 추가 |
| 작성자 | 이서윤 |
| 버전 | v2.0 |
| 관련 화면 | SCR-SALE-01 판매 |
| 상태 | 검토중 |

## 1. 개요
판매 화면에서 바코드 스캐너 또는 태블릿 카메라로 상품 바코드를 읽어 장바구니에 추가한다.
같은 상품을 연속으로 스캔하면 수량이 1씩 늘어난다. 저울 상품(가격 바코드)은 바코드에 포함된 금액을 그대로 사용한다.

## 2. 화면
- 판매 화면(SCR-SALE-01) 상단 검색창 우측 [카메라 스캔] 아이콘
- 외부 스캐너 입력은 화면 어디서든 수신 (입력 포커스와 무관)
- 스캔 성공 시 장바구니 해당 행 0.5초 하이라이트 + "삑" 효과음
- 미등록 바코드 시 하단 에러 토스트 (빨간색, 3초)

## 3. 기능 상세
| No | 요구사항 | 처리 규칙 | 우선순위 |
| --- | --- | --- | --- |
| FS-POS-0018-01 | 지원 규격 | EAN-13, EAN-8, UPC-A, CODE128, 매장 자체코드(20으로 시작 13자리) | 필수 |
| FS-POS-0018-02 | 수량 증가 | 동일 상품 연속 스캔 시 기존 행 수량 +1 | 필수 |
| FS-POS-0018-03 | 가격 바코드 | 21~29로 시작하는 바코드는 7~11번째 자리를 금액(원)으로 해석 | 필수 |
| FS-POS-0018-04 | 판매 중지 상품 | 판매 중지 플래그 상품은 추가하지 않고 안내 | 필수 |
| FS-POS-0018-05 | 카메라 스캔 | 카메라 화면에서 인식 즉시 닫힘, 연속 스캔 모드 토글 제공 | 선택 |

## 4. 입력/출력
| 구분 | 항목 | 형식 | 비고 |
| --- | --- | --- | --- |
| 입력 | 바코드 문자열 | 8~14자리 숫자 또는 CODE128 | 스캐너는 Enter 종료 문자 |
| 출력 | 장바구니 행 | 상품코드, 상품명, 단가, 수량 | 로컬 장바구니에 반영 |
| 출력 | 스캔 로그 | 바코드, 결과코드, 소요시간(ms) | 성능 모니터링용 |

## 5. 예외 처리
| 상황 | 메시지 | 처리 |
| --- | --- | --- |
| 미등록 바코드 | "등록되지 않은 상품입니다. (바코드: {code})" | 에러 토스트, 상품 검색 화면 바로가기 |
| 판매 중지 | "판매가 중지된 상품입니다." | 추가 안 함 |
| 상품 마스터 미동기화 | "상품 정보를 업데이트하는 중입니다." | 로컬 캐시로 조회 후 결과 표시 |

## 6. 권한
- 캐셔 이상 모든 역할 사용 가능
- 가격 바코드 금액 수정은 매니저만 가능 (FS-POS-0024 가격 변경 참조)

## 7. 성능 요구사항
| 항목 | 기준 | 측정 방법 |
| --- | --- | --- |
| 스캔~장바구니 반영 | 300ms 이내 (P95) | 스캔 로그 소요시간 |
| 로컬 상품 캐시 조회 | 50ms 이내 | 상품 5만 건 기준 |
| 연속 스캔 | 초당 3건 이상 누락 없음 | 테스트 스캐너 자동 입력 |
| 오프라인 | 네트워크 단절 시에도 동일 기준 | 로컬 캐시만 사용 |
