# PRD: 주문내역 간편 재주문

| 항목 | 내용 |
| --- | --- |
| 문서 ID | PRD-26-011 |
| 작성자 | 이준호 (서비스기획팀) |
| 이해관계자 | 앱개발팀 김태영, 디자인 오하린, 데이터 윤재석, CS 정다은 |
| 상태 | 승인 |
| 최종 수정 | 2026-03-25 |

## 1. 배경 / 문제
- 생필품·기초화장품 카테고리는 재구매 주기가 30~45일로 짧지만, 재구매 고객의 62%가 검색창에서 상품명을 다시 입력해 찾고 있음 (2026년 1~2월 앱 로그)
- 주문내역 화면에는 배송 조회 외 행동 버튼이 없어, 주문내역 진입 후 이탈률이 71%
- CS 문의 중 "지난번 산 거 어디서 사요?" 유형이 월 140건 발생

## 2. 목표와 비목표
### 목표
- 재구매 고객이 주문내역에서 두 번의 탭 안에 장바구니 담기를 완료한다
- 재구매 주문 중 주문내역 경유 비중을 8% → 25%로 높인다

### 비목표
- 정기배송(구독) 기능은 이번 범위에 포함하지 않는다
- 웹(PC/모바일웹) 적용은 v5.4에서 진행한다
- 주문 당시 가격·쿠폰 복원은 하지 않는다

## 3. 사용자 스토리
| ID | 사용자 | 스토리 |
| --- | --- | --- |
| US-01 | 재구매 고객 | 지난번 산 샴푸를 다시 사고 싶을 때, 주문내역에서 바로 담고 싶다 |
| US-02 | 여러 상품 재구매 고객 | 지난달 주문 2건을 한 번에 다시 담고 싶다 |
| US-03 | 품절 상품 재구매 고객 | 품절이면 다시 들어올 때 알림을 받고 싶다 |

| --- | --- | --- | --- |

| REQ-02 | 동일 옵션·수량으로 담기, 기존 장바구니와 수량 합산 | P0 | US-01 |
| REQ-03 | 품절 옵션 제외 후 담기, 토스트 안내 | P0 | US-01 |

## 5. 수용 기준
- REQ-02: 장바구니에 같은 상품·옵션이 1개 있을 때 수량 2 주문을 다시 담으면 한 행, 수량 3으로 표시된다
- REQ-03: 3개 중 1개가 품절이면 2개만 담기고 "품절 상품 1개를 제외했어요"가 2초간 노출된다
- REQ-05: 가격이 바뀐 상품이 있으면 장바구니 상단에 "가격이 변경된 상품이 있어요" 배너가 노출된다
- REQ-06: 21개 이상 선택 시 담기를 실행하지 않고 한도 안내를 띄운다

## 6. 지표
| 지표 | 정의 | 현재 | 목표 (출시 4주 후) |
| --- | --- | --- | --- |
| 주문내역 경유 재구매 비중 | 주문내역 [다시 담기] 경유 주문 / 재구매 주문 | 8% | 25% |
| 다시 담기 전환율 | 담기 성공 후 24시간 내 결제 / 담기 성공 | - | 35% |
| 주문내역 이탈률 | 주문내역 진입 후 행동 없이 이탈 | 71% | 55% |
| 가드레일: 장바구니 오류 문의 | 장바구니 관련 CS 문의 수 | 월 40건 | 월 50건 이하 |
