# PRD: 상품 리뷰 포토·체형 필터

| 항목 | 내용 |
| --- | --- |
| 문서 ID | PRD-26-014 |
| 작성자 | 김민지 (서비스기획팀) |
| 이해관계자 | 웹개발팀 장도윤, 디자인 오하린, 패션MD 박서연, 데이터 윤재석 |
| 상태 | 리뷰 중 |
| 최종 수정 | 2026-04-14 |

## 1. 배경 / 문제
- 의류 카테고리 반품 사유 1위는 "사이즈 불만"(38%)이며, 리뷰에 키·체중을 적은 비율은 44%로 높지만 필터가 없어 찾기 어려움
- 리뷰 상세 진입 고객의 평균 스크롤 리뷰 수 23개, 원하는 체형 리뷰를 찾다가 이탈
- 경쟁 쇼핑몰 다수가 체형·포토 필터를 제공해 "리뷰 보기 불편하다" VOC가 월 60건

## 2. 목표와 비목표
### 목표
- 고객이 자신과 비슷한 체형의 리뷰를 3번의 탭 안에 찾는다
- 의류 카테고리 사이즈 사유 반품률을 1.5%p 낮춘다

### 비목표
- 리뷰 작성 화면 개편 (체형 정보 입력 UI는 기존 유지)
- AI 리뷰 요약은 별도 PRD(PRD-26-017)에서 다룬다
- 잡화·뷰티 카테고리 적용

## 3. 사용자 스토리
| ID | 사용자 | 스토리 |
| --- | --- | --- |
| US-01 | 키 160cm 고객 | 나와 키가 비슷한 사람이 M을 입었는지 L을 입었는지 보고 싶다 |
| US-02 | 사진 리뷰 선호 고객 | 실제 착용 사진이 있는 리뷰만 모아 보고 싶다 |
| US-03 | MD | 사이즈 불만 리뷰가 몰리는 옵션을 빨리 확인하고 싶다 |

## 4. 요구사항

| REQ-07 | 어드민 옵션별 사이즈 평가 리포트 | P2 | US-03 |

## 5. 수용 기준
- REQ-01: 토글 ON 시 이미지 1장 이상 첨부된 리뷰만 최신순으로 노출, 개수 표시 "포토 128"
- REQ-02/03: 필터는 중복 선택 가능하며 선택 즉시 목록이 갱신된다 (새로고침 없음)
- REQ-05: 리뷰 20개 미만 상품은 요약 바를 노출하지 않는다
- 필터 상태는 같은 세션에서 다른 상품으로 이동해도 유지된다
