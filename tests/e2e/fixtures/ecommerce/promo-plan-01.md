## 1. 기획 배경
- 전년 동기 대비 해당 카테고리 검색량이 증가했고, 경쟁사 기획전이 같은 시기에 열립니다.
- 재고 회전이 느린 상품을 함께 소진할 필요가 있습니다.

## 2. 목표 (KPI)
- 매출 1.2억, 신규 구매자 800명
- 측정 기준: 기획전 페이지 유입 주문 기준

## 3. 행사 개요
| 구분 | 내용 |
| --- | --- |
| 기간 | 2026-03-02 ~ 2026-03-15 |
| 채널 | 자사몰, 오픈마켓 2곳 |
| 혜택 | 커피머신 2+1, 원두 20% 할인 |
| 대상 상품 | 카테고리 대표 상품 30종 |

## 4. 예산
- 총 예산: 1,500만 원 (쿠폰 60%, 광고 30%, 사은품 10%)

## 5. 실행 일정
