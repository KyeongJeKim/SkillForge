# 데이터팀 SQL 작성 규칙 (요약)

| 항목 | 내용 |
| --- | --- |
| 관리 | 데이터분석파트 윤재석 |
| 최종 수정 | 2026-01-12 |
| 적용 범위 | 분석 보고서 첨부 쿼리, 대시보드 원천 쿼리 |

## 1. 파일 헤더 주석 (필수)
모든 .sql 파일 첫 부분에 아래 블록을 둔다.

```sql
/* ============================================================
 * 파일명   : <파일명>.sql
 * 목적     : 한 줄 설명
 * 작성자   : 이름 (팀)
 * 작성일   : YYYY-MM-DD
 * 원천     : schema.table, schema.table
 * 결과     : 컬럼 목록 또는 결과 파일명
 * 변경이력 : YYYY-MM-DD 이름 내용
 * ============================================================ */
```

## 2. 표기
- 키워드·함수는 대문자 (`SELECT`, `FROM`, `LEFT JOIN`, `SUM()`, `DATE_TRUNC()`)
- 테이블·컬럼·별칭은 소문자 snake_case (`order_dt`, `channel_cd`)
- 들여쓰기 4칸, 탭 금지
- 컬럼 목록은 앞 쉼표(leading comma) 방식, 한 줄에 컬럼 하나
- 별칭은 항상 `AS`를 쓴다 (테이블 별칭 포함)

## 3. 구조
- 서브쿼리 대신 CTE(`WITH`)를 쓴다. CTE 이름은 동사 없이 결과를 나타내는 명사 (`orders_base`, `daily_sales`)
- CTE마다 위에 한 줄 주석 `-- [n] 설명`
- 마지막 `SELECT`는 결과 컬럼과 정렬만 담당, 계산은 CTE에서 끝낸다
- `SELECT *` 금지 (CTE 내부 디버깅 시에도 커밋 전 제거)

## 4. 조건과 날짜
- 기간 조건은 `>=` 시작일 AND `<` 종료일 다음날 (`BETWEEN` 금지)
- 날짜 상수는 `DATE 'YYYY-MM-DD'`
- 취소·테스트 주문 제외 조건은 항상 `orders_base` CTE 한 곳에 둔다
  - `order_status_cd NOT IN ('CANCEL', 'TEST')`
  - `is_internal_user = FALSE`

## 5. 금액·비율
- 금액은 원 단위 정수, 나눗셈은 `NULLIF(분모, 0)`으로 0 나눗셈 방지
- 비율 컬럼은 `_rate` 접미사, 소수점 4자리 `ROUND(x, 4)`

## 6. 자주 하는 실수 (리뷰 코멘트 상위)
- 취소 주문 미제외 → 매출 과대
- 주문 테이블과 주문상품 테이블 조인 후 주문수를 `COUNT(*)`로 셈 → `COUNT(DISTINCT order_id)` 사용
- 채널 코드 하드코딩 → `dim_channel` 조인으로 이름 사용
