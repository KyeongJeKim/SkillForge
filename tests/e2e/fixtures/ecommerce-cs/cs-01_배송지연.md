| --- | --- |
| 템플릿 코드 | CS-DLV-01 |
| 문의 유형 | 배송 > 출고 지연 |
| 사용 채널 | 1:1 문의, 채팅 상담 |
| 작성/수정 | 정다은 / 2026-02-14 |

## 사용 조건
- 결제 후 영업일 기준 3일이 지나도 출고되지 않은 주문
- 지연 사유가 확인된 경우에만 사용 (사유 미확인 시 CS-DLV-00 사용)

## 답변 템플릿
안녕하세요, 고객님. 한빛몰 고객행복센터 {상담원명}입니다.

주문하신 {상품명}(주문번호 {주문번호})의 배송 일정 문의 주셨습니다.
기다리시게 해 드려 죄송합니다.

확인해 보니 {지연사유}로 출고가 늦어지고 있으며,
현재 {출고예정일} 출고를 목표로 준비하고 있습니다.
출고되면 알림톡으로 송장번호를 바로 보내 드리겠습니다.

기다리기 어려우시면 주문 취소도 가능하며, 취소 시 결제 수단으로 전액 환불됩니다.
마이페이지 > 주문내역에서 직접 취소하시거나 이 문의에 남겨 주시면 처리해 드리겠습니다.

더 궁금하신 점이 있으시면 언제든 1:1 문의 남겨 주세요.
오늘도 좋은 하루 보내세요. 한빛몰 드림

## 실제 답변 예시 (2026-03-13)
> 고객 문의: 10일에 주문했는데 아직도 배송준비중이에요. 언제 와요? 주말에 입어야 되는데요.

안녕하세요, 고객님. 한빛몰 고객행복센터 정다은입니다.

주문하신 프렌치 린넨 오버핏 셔츠(주문번호 20260310-000123)의 배송 일정 문의 주셨습니다.
주말에 입으실 계획이셨는데 기다리시게 해 드려 죄송합니다.

확인해 보니 스카이블루 M 사이즈의 입고 일정이 늦어져 출고가 지연되고 있으며,
현재 3월 16일(월) 출고를 목표로 준비하고 있습니다.
출고되면 알림톡으로 송장번호를 바로 보내 드리겠습니다.

기다리기 어려우시면 주문 취소도 가능하며, 취소 시 결제 수단으로 전액 환불됩니다.
마이페이지 > 주문내역에서 직접 취소하시거나 이 문의에 남겨 주시면 처리해 드리겠습니다.

더 궁금하신 점이 있으시면 언제든 1:1 문의 남겨 주세요.
오늘도 좋은 하루 보내세요. 한빛몰 드림
