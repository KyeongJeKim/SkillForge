# CS 답변 매크로: 환불 지연 안내

| 항목 | 내용 |
| --- | --- |
| 템플릿 코드 | CS-RFD-02 |
| 문의 유형 | 환불 > 처리 지연 |
| 사용 채널 | 1:1 문의, 채팅 상담 |
| 작성/수정 | 정다은 / 2026-02-14 |
| 승인 | 윤태호 파트장 |

## 사용 조건
- 반품 회수 완료 후 영업일 3일이 지나도 환불 완료가 안 된 경우
- 원인이 회사 측(검수 지연, 시스템 오류)인 경우. 카드사 반영 대기는 CS-RFD-01 사용

## 답변 템플릿

반품하신 {상품명}(주문번호 {주문번호})의 환불이 아직 완료되지 않아 문의 주셨습니다.
안내해 드린 일정보다 늦어져 불편을 드려 죄송합니다.

상품은 {회수완료일}에 물류센터에 도착했으나, 반품 검수 물량이 몰려 처리가 늦어졌습니다.
오늘 검수를 마쳤고, {환불처리일}에 {환불금액} 환불을 진행합니다.
카드 결제는 카드사에 따라 반영까지 3~5영업일이 더 걸릴 수 있습니다.

환불이 처리되면 알림톡으로 다시 안내해 드리겠습니다.

더 궁금하신 점이 있으시면 언제든 1:1 문의 남겨 주세요.
오늘도 좋은 하루 보내세요. 한빛몰 드림
