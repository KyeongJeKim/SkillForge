한빛몰 고객행복센터 답변 톤 가이드 (요약본)
최종 수정: 2026-02-14 / 관리: CS운영파트 정다은

1. 기본 원칙
 - 호칭은 항상 "고객님". "회원님", "님" 단독 사용 금지.
 - 존댓말은 "~합니다/~드립니다"체 기본, 문장 끝 "~요"체는 공감 문장에만 사용.
 - 이모지, 이모티콘, 느낌표 연속(!!) 사용 금지. 느낌표는 답변 전체에서 1회 이내.
 - 사과는 한 번만, 구체적으로. ("불편을 드려 죄송합니다" O / "정말 정말 죄송합니다" X)
 - 내부 용어(WMS, 출고지시, 클레임코드 등)는 고객 답변에 쓰지 않는다.

2. 고정 구성 (순서 지킬 것)
 ① 인사: "안녕하세요, 고객님. 한빛몰 고객행복센터 {상담원명}입니다."
 ② 문의 확인: 주문번호/상품명을 넣어 고객 상황을 한 줄로 확인
 ③ 공감 또는 사과 (필요한 경우만)
 ④ 안내: 처리 내용, 일정, 고객이 할 일 순서로
 ⑤ 다음 단계: 언제 무엇을 다시 안내하는지
 ⑥ 맺음: "더 궁금하신 점이 있으시면 언제든 1:1 문의 남겨 주세요.
          오늘도 좋은 하루 보내세요. 한빛몰 드림"

3. 숫자/일정 표기
 - 날짜는 "3월 12일(목)" 형식, 금액은 "6,000원" (쉼표 + 원)
 - "최대한 빨리", "곧" 같은 모호한 표현 대신 영업일 기준 일정을 쓴다.

4. 금지 표현
 - "규정상 어렵습니다" 단독 사용 (대안 없이 거절 금지)
 - "고객님 잘못으로", "확인 안 하셨나요" 등 책임 전가 표현
 - 보상 금액 확답 (보상은 파트장 승인 후 별도 안내)
