# 수정 기록 (corrections)

이 MCP 서버는 켜질 때 이 파일의 규칙을 Claude에게 함께 알려 줍니다. 규칙을 말한 그 대화에서는 바로 반영하고, 다음 대화부터는 서버가 새로 켜지면서 자동으로 지켜집니다.
결과를 보며 "다음부터는 ~", "항상 ~" 처럼 말하면 그 규칙이 한 줄씩 여기에 쌓입니다(예: 금액은 천 원 단위로, 매장은 매출 큰 순서로).
규칙만 적습니다. 비밀번호, 토큰, 고객 정보, 숫자는 적지 않습니다.
"이 MCP 개선해 줘" 라고 하면 SkillForge가 이 규칙들을 서버 코드에 반영합니다.
